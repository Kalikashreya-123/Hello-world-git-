# Hello World

A small, self-contained website with a polished welcome page, an About page, and a Contact page. The pages share a responsive design and navigation, with no build tools or dependencies required.

## Pages

- `index.html` — Home page with an interactive hello button.
- `about.html` — A short introduction to the project.
- `contact.html` — Contact information and an email link.

## View the site

Open `index.html` in a web browser. Use the navigation at the top of each page to move between Home, About, and Contact.

## Customize

Update the text in the HTML files to make the site your own. The Contact page currently uses the placeholder email address `hello@example.com`; replace it in the `mailto:` link in `contact.html` with your email address.
